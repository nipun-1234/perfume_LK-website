## ✨ Perfume.lk — Luxury 3D Fragrance Experience

Perfume.lk is a premium 3D fragrance e-commerce experience inspired by the beauty and heritage of Ceylon. The project combines modern web technologies, interactive 3D visuals, and a luxury-inspired UI to create an immersive perfume shopping experience.

### 🌟 Key Features

- 🧴 Interactive 3D perfume bottle experience
- ✨ Real-time bottle customization
- 🎨 Custom fragrance liquid and cap finishes
- ✍️ Personalized bottle engraving
- 🌿 Interactive Ceylon-inspired scent notes explorer
- 💨 Interactive fragrance spray particle effects
- 🎯 Bespoke Scent Finder quiz
- 🛍️ Interactive fragrance collection and shopping cart
- 💱 LKR / USD currency switching
- 🔊 Web Audio sensory effects
- 📱 Responsive design for desktop, tablet and mobile
- ⚡ Optimized 3D WebGL experience

### 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Build Tool:** Vite
- **3D:** Three.js / WebGL
- **Animations:** GSAP
- **Icons:** Lucide Icons
- **Graphics:** HTML Canvas
- **Audio:** Web Audio API
- **Styling:** Glassmorphism + Luxury Dark UI
- **Currency:** LKR / USD

### 🎨 Design Concept

The visual identity is inspired by **Ceylon Haute Parfumerie**, combining:

- Obsidian Black `#08080a`
- Champagne Gold `#d4af37`
- Frosted Glass effects
- Luxury serif typography
- Modern geometric body typography
- Ambient lighting and particle effects
